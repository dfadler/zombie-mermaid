# State of the fork — 2026-08

Period covered: 2026-08-15 (repo created) to 2026-08-31.

This is the first report, so it covers the fork's whole life to date rather
than a clean calendar month. Every figure below traces to a `gh`/`git`
command run against `dfadler/zombie-mermaid` (and, for the "vs. upstream"
section, `lukilabs/beautiful-mermaid`) on 2026-08-31 — see each section for
the exact command.

## Releases shipped

<!-- gh release list --repo dfadler/zombie-mermaid --limit 10 -->

Four releases, all in the second half of August:

- **v1.2.0** (2026-08-27) — new `zombie-mermaid` CLI (`render`, `themes`,
  `--ascii`/`--svg`), a CommonJS build alongside ESM (fixes
  `ERR_PACKAGE_PATH_NOT_EXPORTED` on `require()`), and configurable font
  sizes / sequence-diagram spacing via `RenderOptions`.
- **v1.3.0** (2026-08-28) — closes several flowchart syntax gaps against the
  Mermaid spec found during a dedicated audit (#198): expanded node shape
  syntax, `click`/`%%{init:...}%%` directives, edge curve styles and
  animated edge IDs, semicolon statement separators across all diagram
  types.
- **v1.4.0** (2026-08-28) — adds `embedSource` to stamp diagram source onto
  the rendered `<svg>`; fixes a dead Google Fonts `@import` baked into SVG
  output when `font` is a stack or generic keyword.
- **v1.5.0** (2026-08-30) — adds `RenderOptions.interactivity` (tiered
  animation/interactivity control), state-diagram edge-id animation syntax,
  and `title`/`decorative` options so rendered SVGs carry an accessible
  name (WCAG 1.1.1).

The `CHANGELOG.md` entries dated Jan–Feb 2026 (v0.1.3 through v1.1.3) predate
this fork — they're `beautiful-mermaid`'s own pre-fork history and aren't
counted here.

## Fixes traced to upstream issues

<!-- grep -oP "upstreamIssues:\s*\[\K[^\]]+" demo/fork-fixes-data.ts | tr ',' '\n' | tr -d ' ' | sort -nu | wc -l -->

**23 distinct `lukilabs/beautiful-mermaid` issues** have a confirmed fix in
this fork, each demonstrated with a live before/after render on the
["what this fork fixes" page](../../demo/fork-fixes-data.ts) (generated by
`fork-fixes.ts` — every pair is rendered from the actual pre-fix and current
renderer, not hand-drawn, and the generator fails the build if a pair ever
renders identically). This is the fork's first report, so all 23 are new
this period; there's no prior baseline to diff against.

Representative fixes: bare-node-id arrows silently dropping edges
(upstream #140), CJK subgraph ids resolving to an empty string (#89), CJK
label widths overflowing their own ASCII box (#12, #13, #119, #122), and ER
"zero or more" cardinality strings that silently dropped the relationship
they annotated (#124). The full list, each with its source diagram and PR,
is in `demo/fork-fixes-data.ts`.

## PR-rescue progress

None yet. [Issue #258](https://github.com/dfadler/zombie-mermaid/issues/258)

independently in this fork's own code, not ported from an existing upstream
