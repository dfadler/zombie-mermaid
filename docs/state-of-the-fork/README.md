# State of the fork

A recurring report on where `zombie-mermaid` stands versus upstream
(`lukilabs/beautiful-mermaid`): releases shipped, fixes traced to upstream
issues, PR-rescue progress, and general activity. See
[issue #259](https://github.com/dfadler/zombie-mermaid/issues/259) for why
this exists — it's the promotion case for the fork, made of numbers instead
of adjectives.

## Cadence

Monthly, or whenever there's enough to say. A thin month is worth a short
report more than a skipped one — the value is in the trend line, not any
single entry.

## Producing a report

1. Copy [`TEMPLATE.md`](TEMPLATE.md) to `YYYY-MM.md` (the month the report
   covers).
2. Fill in every field using the commands the template lists next to it.
   Every number needs to trace back to a command you actually ran, a file
   you actually read, or a query you actually made — see this repo's
   `CLAUDE.md` on not fabricating statistics. If a metric genuinely isn't
   available (no access to a service, nothing happened in that category),
   say so explicitly rather than omitting the line or guessing.
3. Add the new report to the table below.
4. Optionally, post it as a GitHub Discussion or a pinned issue — the doc
   under `docs/state-of-the-fork/` is the source of record either way, so a
   post elsewhere can just link back here.
